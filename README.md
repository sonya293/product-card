# Магазин: карточки товара со счётчиком (React + Vite)

## Запуск
1. Установите Node.js (https://nodejs.org, версия 20 или новее).
2. В папке проекта выполните:

   npm install
   npm run dev

3. Откройте адрес из терминала (обычно http://localhost:5173).

## Структура
- src/App.jsx          — главный компонент, выводит список карточек
- src/ProductCard.jsx  — карточка товара (props: name, price, image) + useState-счётчик
- src/ProductCard.css  — стили карточки
